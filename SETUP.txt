MyHealth Appointment — setup (do this once)

1. Create a free project at https://supabase.com
2. Open SQL Editor, paste and run the file: supabase/schema.sql
3. Project Settings -> API:
   - copy Project URL
   - copy anon public key  (NOT the service_role key)
4. Open local.properties in this folder and set:

   sdk.dir=C:\\Users\\sedra\\AppData\\Local\\Android\\Sdk
   SUPABASE_URL=https://YOUR_PROJECT_REF.supabase.co
   SUPABASE_ANON_KEY=your_anon_key_here

5. In Android Studio: File -> Sync Project with Gradle Files
6. Run the app on an emulator with internet.

Login
- Patients log in with EMAIL and PASSWORD.
- There is no email confirmation or verification email.
- Register saves the account immediately. You can log in right away.
